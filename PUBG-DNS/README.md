# PUBG DNS — پروژه داخل مخزن IR_Khatary

این پروژه در پوشهٔ جداگانهٔ `PUBG-DNS/` نگهداری می‌شود تا فایل‌های نسخهٔ فعلی IR_Khatary DNS دست‌نخورده بمانند.

## وضعیت فعلی
- پروژهٔ پایهٔ Android با Java و رابط تیرهٔ مخصوص بازی
- انتخاب نام سرویس DNS و ذخیرهٔ انتخاب کاربر
- درخواست اجازهٔ Android VPN از کاربر، پیش از شروع سرویس
- پشتیبانی هدف Android 8 تا 15

**مهم:** این کامیت یک اسکلت توسعه است؛ سرویس هنوز بسته‌های DNS را به‌صورت کامل عبور نمی‌دهد و نباید وضعیت آن را اتصال واقعی یا بهبود قطعی پینگ دانست. پیش از انتشار باید پیاده‌سازی DNS forwarding و آزمایش روی گوشی واقعی تکمیل شود.

## ساخت
پروژه را در Android Studio باز کنید و Gradle Sync را اجرا کنید. برای ساخت APK از گزینهٔ Build APK استفاده کنید.
