## نسخه
- Version: 1.0
- Android versionCode: 1
- Android versionName: 1.0

## ساخت APK
1. به بخش **Actions** مخزن بروید.
2. گردش‌کار **Build IR_Khatary Android APK** را اجرا کنید.
3. فایل خروجی را از بخش Artifacts دانلود کنید.

## وضعیت فنی
این گردش‌کار در حال حاضر APK را از رابط و کد اندرویدی که داخل فایل workflow تعریف شده می‌سازد. ایجاد رابط VPN به‌تنهایی به معنی عبور واقعی درخواست‌های DNS نیست؛ قبل از استفاده برای پابجی، باید ارسال و دریافت DNS روی گوشی واقعی آزمایش شود. این نسخه تضمین پینگ پایین یا دور زدن محدودیت شبکه را نمی‌دهد.
