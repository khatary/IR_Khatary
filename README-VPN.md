# IR_Khatary VPN — نسخه توسعه 1.1.0

هدف این نسخه، اتصال واقعی داخل خود برنامه به سرورهای عمومی رایگان VPN Gate است؛ کاربر نباید برای اتصال به برنامه VPN دیگری هدایت شود.

## روش ساخت فعلی
گردش‌کار GitHub Actions از پروژه متن‌باز [VPN Gate Connector](https://github.com/hoang-rio/vpngate-connector) با پیاده‌سازی بومی SoftEther استفاده می‌کند، نام نمایشی را به IR_Khatary VPN تغییر می‌دهد و تلاش می‌کند نسخه Debug را بسازد. منبع اصلی تحت GPLv3 است؛ هر نسخهٔ مشتق‌شده باید الزامات همان مجوز، از جمله انتشار کد منبع متناظر و حفظ اطلاعیه‌های مجوز را رعایت کند.

## ساخت APK
1. [بخش Actions مخزن](https://github.com/khatary/IR_Khatary/actions) را باز کنید.
2. گردش‌کار **Build IR_Khatary VPN APK** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. فقط اگر اجرا با وضعیت موفق (سبز) تمام شد، artifact با نام `IR-Khatary-VPN-v1.1.0-APK` را دریافت کنید.

## مهم
- این تغییر تلاش می‌کند یک کلاینت واقعی با پشتیبانی VPN Gate/SoftEther را در APK قرار دهد؛ این با نسخه قبلی که فقط برنامه Proton VPN را باز می‌کرد متفاوت است.
- **ساخت موفق APK هنوز تأیید نشده است.** اگر GitHub Actions خطا بدهد، باید لاگ‌ها بررسی و خطاها اصلاح شوند؛ تا آن زمان نباید این نسخه را آماده و قابل اتصال دانست.
- VPN Gate سرورهای داوطلبانه دارد؛ دسترس‌پذیری، سرعت و حریم خصوصی بین سرورها متفاوت است. بعضی سرورها ممکن است آفلاین شوند یا سیاست ثبت گزارش متفاوتی داشته باشند. قبل از استفاده از ترافیک حساس، سیاست سرور را بررسی کنید.
- این پروژه سرور اختصاصی خریداری یا ایجاد نمی‌کند.
- برای انتشار، مجوز GPLv3 و مجوزهای وابستگی‌ها باید رعایت شوند.
