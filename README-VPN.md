# IR_Khatary VPN — نسخه 1.0

پروژهٔ اندرویدی VPN با رابط فارسی و کتابخانهٔ رسمی WireGuard برای تونل رمزگذاری‌شده.

## ساخت APK رایگان
1. در مخزن GitHub به بخش **Actions** بروید.
2. گردش‌کار **Build IR_Khatary VPN APK** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از اتمام موفق ساخت، از بخش Artifacts فایل `IR-Khatary-VPN-v1.0-APK` را دریافت کنید.

ساخت APK در GitHub Actions انجام می‌شود و برای ساخت برنامه نیاز به خرید ابزار توسعه نیست.

## راه‌اندازی اتصال واقعی
- برنامه از فایل کانفیگ استاندارد WireGuard با پسوند `.conf` استفاده می‌کند.
- در برنامه گزینهٔ «وارد کردن فایل .conf» را انتخاب کنید و کانفیگ سروری را وارد کنید که مجاز به استفاده از آن هستید.
- سپس «اتصال امن» را بزنید و مجوز VPN اندروید را تأیید کنید.
- اگر سرور، کلیدها، endpoint یا دسترسی شبکه معتبر نباشند، اتصال برقرار نمی‌شود و برنامه وضعیت اتصال موفق نشان نمی‌دهد.

## نکته دربارهٔ هزینه و سرور
این مخزن به‌تنهایی سرور VPN ایجاد نمی‌کند. برای VPN عمومی و قابل‌استفاده از بیرون، یک سرور WireGuard فعال لازم است. گزینه‌هایی مانند Oracle Cloud Free Tier ممکن است منابع Always Free ارائه کنند، اما ثبت‌نام و تأیید حساب ممکن است کارت بانکی بخواهد، ظرفیت منطقه تضمین نیست و رعایت محدودیت‌های رایگان ضروری است. قبل از ارتقا به حساب پولی، مطمئن شوید که هیچ منبع پولی ایجاد نکرده‌اید.

## امنیت
فایل کانفیگ WireGuard شامل کلید خصوصی است. آن را عمومی نکنید و به مخزن GitHub نفرستید. برنامه کانفیگ واردشده را در فضای خصوصی داخلی اپ ذخیره می‌کند. فقط از کانفیگ‌هایی استفاده کنید که مالک آن هستید یا اجازهٔ استفاده دارید.

## محدودیت فعلی
- برنامهٔ اندروید و اتصال WireGuard از کتابخانهٔ رسمی tunnel پیاده‌سازی شده‌اند.
- این تغییر به‌تنهایی سرور رایگان provision نمی‌کند و کانفیگ آماده در اختیار نمی‌گذارد.
- وضعیت «تونل فعال» فقط پس از پذیرفته‌شدن وضعیت UP از backend نمایش داده می‌شود؛ با این حال، وضعیت UP به‌تنهایی تضمین نمی‌کند که اینترنت یا DNS از سمت سرور درست کار می‌کند. برای انتشار عمومی باید روی دستگاه واقعی، handshake و تبادل ترافیک و نبود نشت DNS آزمایش شود.
